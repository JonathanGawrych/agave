# Vanity word bank. Curate this list, then save and close to continue.
#
# RULES
#   * Words are matched at their REAL length. 3-letter words match 3 characters,
#     4-letter words match 4. Nothing is truncated or padded.
#   * base58 only: 0 O I l are NOT valid characters.
#     Write O as o, I as i, and l as L.  GOLD -> GoLD, KING -> KiNG
#   * Every word is tried as both a prefix and a suffix.
#   * Delete or `#`-comment any word you don't want.
#
# LEET VARIANTS are generated automatically (a4 b8 e3 g6 i1 s5 t7 z2), matched
# case-insensitively, and the first character is never substituted. So BEST also
# matches B3ST BE5T BES7 B35T B3S7 BE57 B357, and Paws also matches P4ws Paw5
# P4w5. A word with no substitutable letters after the first (GoLD, DoNG, Bun)
# generates no variants.
#
# WORD LENGTH AND HIT VOLUME
#   A 3-letter word is ~180x more likely to hit than a 4-letter one:
#     FUR   as suffix ~27 min,     as prefix ~16 min   (1 device @15/s)
#     GoLD  as suffix ~52 hr,      as prefix ~30 hr
#   Adding 3-letter words does NOT slow down 4-letter discovery. The scan rate
#   is fixed and every key is checked against everything, so it only adds
#   registry lines. The registry records match_len, so you filter later:
#     jq 'select(.match_len>=4)' registry.jsonl
#   A *specific* 4-letter word is expensive (30-50 hr). The ~11 min figure for
#   "any 4-letter hit" only holds because ~140 of them are matched at once, so
#   keep the 4-letter list broad.
#
# WHY SOME WORDS ONLY EVER LAND AT THE END
#   A base58 address's first character is not uniform: 2-9 and A-H are 5.90%
#   each, J is 1.43%, and K-Z / a-z are 0.10% each (59x rarer). So a word like
#   KiNG is tried as a prefix but will realistically only ever appear as a
#   suffix. Nothing to do about it, just don't be surprised.
